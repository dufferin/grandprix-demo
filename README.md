# Grandprix Demo v2 (Option A + แอพกลาง)

Clickable demo ของแนวคิด **Grandprix Account + CRM + ร้านค้าในหน้าซื้อตั๋ว** และ **แพลตฟอร์มกลาง multi-tenant ที่ขายต่อผู้จัดงานรายอื่นได้** — ไฟล์เดียว `index.html` ไม่มี backend

> **ล่าสุด:** แพ็ก Basic / Plus + feedback รอบ 2026-10-05 (ดูหัวข้อแรก) · ก่อนหน้า: ปรับตาม redesign v2 จาก Claude Design + เพิ่ม LINE OA จำลอง (`#/line`) — ดูหัวข้อ "Redesign v2" ด้านล่าง
>
> v2 = demo เดิมทั้งหมด + หน้าใหม่ 6 หน้าในหัวข้อ "ของใหม่ใน v2" ด้านล่าง · state key เดิม `gp_demo_v2` (ของเก่ายังใช้ได้ ไม่ต้องรีเซ็ต)

## เปิดใช้งาน

```bash
python3 -m http.server 5199 --directory demo
```

แล้วเปิด http://localhost:5199 (หรือเปิด `index.html` ตรง ๆ ใน browser ก็ได้)

| **ยอดใช้งาน & ค่าบริการ (`#/admin/billing`)** | หน้าที่ลูกค้าเปิดดูเองได้ — **โมเดลตาม fact sheet:** สัญญารายปี (Basic 60,000/ปี · Plus 118,800/ปี · แสดงเฉลี่ยต่อเดือนคู่กัน) + โควตา (ผู้ใช้ · รายชื่อ · พื้นที่ · อีเมล) พร้อมปุ่มซื้อเพิ่ม · ค่าบริการจากยอดขายสินค้าขั้นบันไดตั้งแต่บาทแรก 0–250,000 5% / 250,000–500,000 4% / เกิน 500,000 3% · **นับยอดสดจากคำสั่งซื้อใน demo และหักคืนเงินอัตโนมัติ** · ใบแจ้งหนี้: ค่าแพ็กรายปี + ค่าบริการสินค้ารายเดือน · **อัปเกรดกลางปีจ่ายส่วนต่างตามเดือนที่เหลือ · ลด Plus → Basic เด้ง modal เงื่อนไข "ปีนั้นคิด Plus เต็มปี ไม่คืนเงิน"** |

## ปรับรอบ 2026-10-08 · ล่าสุด

> ถ้าเคยเปิด demo ในเครื่องนี้แล้ว ให้กด **รีเซ็ต** ในแถบ demo หนึ่งครั้ง เพื่อล้างข้อมูลเก่าใน localStorage

- **สินค้าแนะนำจากสปอนเซอร์:** ลิงก์ได้เฉพาะเว็บไซต์ของสปอนเซอร์ (Shopee / Lazada / TikTok บันทึกไม่ได้) · การ์ดมีรูปสินค้าจำลอง · กดแล้วไปหน้าเว็บไซต์สปอนเซอร์จำลอง (ชื่อร้านสมมุติ) · CPS ใช้สคริปต์บนเว็บสปอนเซอร์ส่งยอดกลับ · CPC ไม่เกินงบ · คลิกซ้ำวันเดียวกันนับ 1
- **ส่วนลด & โปรโมชัน:** เป็นตาราง ค้นหา / กรองได้ · ปุ่ม "สร้างโค้ด" เปิด modal
- **แคมเปญ:** ผู้รับ = ในกลุ่ม − ไม่ยินยอม − ไม่มีช่องทาง · funnel เปิดของ LINE แสดง "–" เมื่อผู้รับน้อยกว่า 20 คน · ลบได้เฉพาะร่าง · กลุ่มที่สร้างเองใช้ยิงแคมเปญได้
- **คำสั่งซื้อ:** เปลี่ยนสถานะตามลำดับที่อนุญาต · ยกเลิกหลังจ่าย = คืนเงินทั้งหมด (คืนสต็อก) · คืนเงินเลือกบรรทัดได้ รวมค่าส่ง ยอดหักส่วนลดที่ปันแล้ว · สถานะจัดส่งกับสถานะ order ตรงกัน
- **สต็อก:** ใส่ตะกร้าเกินสต็อกไม่ได้ · สินค้าหมดกดซื้อไม่ได้
- **การจัดส่ง:** order ที่ซื้อจริงเข้าคิว "รอแพ็ก" · มีเฉพาะสินค้าที่ชำระแล้ว · ปุ่มเลื่อนสถานะขนาดเท่ากัน
- **ค่าบริการร้านค้า:** ฐาน = ยอดที่ลูกค้าจ่าย รวมค่าส่ง หักส่วนลดและคืนเงิน (ไม่รวมค่าสมัคร / ตั๋ว) · ช่วง 0 – 250,000 · 250,001 – 500,000 · 500,001 ขึ้นไป · ตัวเลข Platform กับหน้าแพ็กเกจตรงกัน
- **ลดแพ็ก Plus → Basic:** มีผลตอนต่ออายุ ใช้ Plus ได้ถึงวันครบรอบ · ยกเลิกการลดได้
- **สมัครสมาชิก:** ความยินยอมแยก 3 ข้อ ไม่ติ๊กไว้ให้
- **ตัดออกตาม spec:** ลิงก์ไป Platform Console จากหลังบ้านลูกค้า · ลิงก์ "ดูใน CRM" หลังจ่ายเงิน · ช่อง SMS · ส่วน Activity & Task · object สินค้า/ผู้สมัครใน view engine · การ์ดสปอนเซอร์ใน LINE
- **UI:** dropdown ลูกศรห่างกรอบเท่ากันทุกที่ · modal ฟอร์มระยะห่างกระชับขึ้น

### โครงเมนู Back-office (ปรับล่าสุด)

```
📊 ภาพรวม
👥 ลูกค้า              → View engine · แท็บย่อย: ลูกค้า / Top spender & Customer 360 / กลุ่มลูกค้า
🛍️ สินค้า              → แท็บย่อย: รายการสินค้า / คลังสินค้า
📦 คำสั่งซื้อ           → รายการคำสั่งซื้อ (#/admin/orders) · แท็บย่อย: คำสั่งซื้อ / การจัดส่ง (view engine) / ศูนย์จัดส่ง

🏷️ ส่วนลด & โปรโมชัน
📣 แคมเปญ              → มีแท็บลัดไปกลุ่มลูกค้า

🧾 ยอดใช้งาน & ค่าบริการ
```

**หลักที่ใช้จัด:** เมนูหลักคือ **object ที่คนทำงานด้วย** (ลูกค้า · สินค้า · คำสั่งซื้อ) ส่วนมุมมองและเครื่องมือย่อยเป็นแท็บอยู่ข้างใน

### จุดที่ปรับตาม feedback ล่าสุด
- **Grandprix Account** = หน้า login กลาง (โลโกทุก event) + หน้า **บัญชีของฉัน** เท่านั้น — เอาหน้า portal รวมออก และ**ไม่มี logout**
- **Top spender รวมกับ CRM** — กรองตามประเภทได้ เช่น TDE + "ตั๋ว / บัตร" = คนที่เคยซื้อบัตรจริง (ไม่รวมคนที่ซื้อแต่ของที่ระลึก) แล้วติ๊กเลือก → "ชวนกลับมาปีหน้า"
- **หน้าสรุปยอดของ event** ซื้อของที่ระลึกพ่วงและจ่ายพร้อมกันได้ · **event ปิดแล้ว → redirect ไป marketplace**
- **ตัวเลือกสินค้า** (มี/ไม่มีตัวเลือก, ชื่อกลุ่ม, เพิ่ม-ลบไซส์) ตั้งค่าได้ใน Back-office › สินค้า แล้วมีผลทั้งหน้าร้านและ add-on ทันที
- **แชท** เหลือช่องทางเดียวของ marketplace และมีเฉพาะในหน้าร้าน
- **OTP ทาง email อย่างเดียว** (ตัด OTP SMS ออก)

### วิธีเล่น
- เริ่มที่ **สารบัญ demo** (`#/`) แล้วไล่ตามขั้นตอน 1–9 · ปุ่ม **รีเซ็ต** บนแถบด้านบนล้างข้อมูล demo (ใช้แทน logout)
- Login ครั้งเดียว → ทุกเว็บ login อยู่แล้ว (จำลอง SSO ด้วย localStorage) · เปิด 2 แท็บ (หน้าร้าน + Back-office) จะเห็นข้อมูล sync กันทันที
- โค้ดส่วนลด: `SU10` (Souped Up 10%), `TDE100` (TDE ลด 100 ขั้นต่ำ 500), `GPRC50` (Runbike ลด 50) · สร้างโค้ดใหม่เองได้ที่ Back-office › ส่วนลด & โปรโมชัน
- แก้ราคา / stock / ตัวเลือก / ปิดขายที่ Back-office › สินค้า แล้วหน้าร้านและหน้าสรุปยอดเปลี่ยนทันที · สลับ role เป็น event-admin การแก้จะเข้าคิว **"รออนุมัติ"** (ของเดิมยังขายต่อจนกว่า super-admin จะอนุมัติ) · จ่ายเงินแล้ว stock ตัดอัตโนมัติ

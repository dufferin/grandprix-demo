# Grandprix CRM + Marketplace + LINE OA · Demo

เปิดใช้งาน: **https://dufferin.github.io/grandprix-demo/**

Demo หน้าเดียว (HTML + JavaScript) ข้อมูลทั้งหมดเป็นตัวอย่าง เก็บไว้ในเบราว์เซอร์ของผู้เปิด (localStorage) ไม่มีการส่งข้อมูลออกไปที่ไหน

## มีอะไรให้ลอง

- **หน้าเว็บงาน** TDE · Souped Up · Runbike → ซื้อตั๋วพร้อมของที่ระลึก จ่ายครั้งเดียว
- **Marketplace** ร้านรวมทุกงาน · ตะกร้า · โค้ดส่วนลด · คำสั่งซื้อของฉัน
- **Grandprix Account** login กลาง (LINE / อีเมล) · บัญชีของฉัน
- **LINE OA (จำลอง)** rich menu · ตั๋ว QR · แจ้งสถานะจัดส่ง
- **Back-office**
  - แพ็ก Basic: ภาพรวม · ลูกค้า + Customer 360 · กลุ่มลูกค้า · สินค้า / คลัง · คำสั่งซื้อ · การจัดส่ง · แชทหน้าร้าน · ส่วนลด & โปรโมชัน · แพ็กเกจ & ค่าบริการ
  - แพ็ก Plus: แคมเปญ LINE OA + อีเมล · แชทรวม LINE + Facebook · ติดตามพัสดุอัตโนมัติ · สินค้าแนะนำจากสปอนเซอร์

## วิธีเล่น

1. เปิดหน้าแรก (สารบัญ demo) แล้วเลือกจุดเริ่ม
2. สลับแพ็ก Basic / Plus ที่ Back-office › แพ็กเกจ & ค่าบริการ
3. แถบ demo ด้านบนมีปุ่ม **รีเซ็ต** สำหรับล้างข้อมูลกลับเป็นค่าเริ่มต้น

## หมายเหตุ

- ราคาทั้งหมดยังไม่รวม VAT · ตัวเลขยอดขายเป็นตัวอย่าง ไม่ใช่การคาดการณ์
- เว็บไซต์ของสปอนเซอร์ที่ลูกค้าถูกพาไปเป็นหน้าจำลอง ชื่อร้านเป็นชื่อสมมุติ
